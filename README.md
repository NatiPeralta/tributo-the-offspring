# 🎸 Tribute Page - The Offspring

Uma página de tributo dedicada à banda de punk rock **The Offspring**, desenvolvida para praticar a estruturação semântica de páginas web, estilização avançada, tipografia e organização de layouts com HTML5 e CSS3.

O projeto foi criado como exercício prático durante o curso **Formação Front-end** ministrado pelo portal **Hora de Codar** na Udemy.

---

## 🚀 Destaques do Projeto

- 📄 **Estrutura Semântica:** Uso adequado de tags HTML5 para melhoria de acessibilidade e SEO.
- 🎨 **Estilização Temática:** Layout moderno e personalizado combinando com a identidade visual e história da banda.
- 📐 **Layout Responsivo:** Adaptação visual fluida para telas de computadores e dispositivos móveis.
- 🖼️ **Galeria e Linha do Tempo:** Apresentação estruturada de fotos, integrantes, biografia e discografia principal.

---

## 🛠️ Tecnologias Utilizadas

- **[HTML5](https://developer.mozilla.org/pt-BR/docs/Web/HTML):** Estruturação semântica do conteúdo.
- **[CSS3](https://developer.mozilla.org/pt-BR/docs/Web/CSS):** Estilização, regras de layout (Flexbox/Box Model) e tipografia.
- **[Git & GitHub](https://github.com/):** Controle de versão do código.
